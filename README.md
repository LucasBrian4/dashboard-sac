# Dashboard SAC

![Power BI](https://img.shields.io/badge/Power_BI-F2C811?style=flat&logo=powerbi&logoColor=black)
![Excel](https://img.shields.io/badge/Excel-217346?style=flat&logo=microsoftexcel&logoColor=white)

Dashboard de atendimento ao cliente com dados de **2023 a 2025**,
construído no Power BI para monitorar performance do SAC.

---

## Principais insights

- Total de atendimentos: **12 mil**
- Tempo médio por atendimento: **5,63 minutos**
- Média de dias para retorno: **2,26 dias**
- Média diária de chamados: **10,96**
- Taxa de cancelamento: **19,36%**
- Problema mais frequente: **Recursos** e **Emissão de certificado** (~1,3 mil cada)
- Atendente com mais chamados: **Matheus Ru. (362)**, seguido de Jeferson Ra. (350)
- Volume estável ao longo dos 3 anos, sem mudanças expressiva
